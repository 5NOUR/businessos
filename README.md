# BusinessOS

BusinessOS is a multi-tenant business management SaaS platform for SMBs.

## Project Structure

- `apps/web`: Frontend (React + Vite + TypeScript)
- `apps/api`: Backend (NestJS + TypeScript)
- `packages/types`: Shared TypeScript types
- `packages/config`: Shared configuration (e.g., TypeScript)
- `packages/eslint`: Shared ESLint configurations

## Getting Started

```bash
pnpm install
pnpm dev:web
pnpm dev:api
```
